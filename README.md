# TradingBots — Автоматический торговый бот

Проект бумажного трейдинга на Python. 4 бота под разные режимы рынка,
Market Regime детектор, ML фильтры, автоматический журнал сделок.

---

## Архитектура

```
market_regime.py (каждые 30 мин)
  ├── TREND_UP / TREND_DOWN → Бот #1 Адаптивный  (Bitget spot, 5m)
  ├── SIDEWAYS              → Бот #1 + Бот #2     (Bitget / Binance)
  ├── BREAKOUT              → Бот #4 Breakout     (Binance, 15m/1h)
  └── VOLATILE              → пауза

Бот #3 Funding Rate — работает независимо от режима (Bitget фьючерсы, 1h)

shared_state.json ← market_regime.py пишет каждые 30 мин
      ↓
все боты читают режим → выбирают стратегию входа
      ↓
ml_data_collector.py → единый датасет (regime, signal_type, exchange, ...)
```

## Боты

### Бот #1 — Адаптивный (Bitget spot, 5m)
**Режим:** TREND_UP / TREND_DOWN / SIDEWAYS

**Стратегия меняется по режиму рынка:**

```
TREND_UP / TREND_DOWN → Channel Breakout
  Пробой 15-свечного канала с объёмом > 1.5x
  Вход на закрытии пробойной свечи
  Стоп за противоположный край канала
  RR 1:3

SIDEWAYS → Mean Reversion
  RSI < 35 + цена у нижней BB (±1%) → лонг к средней BB
  RSI > 65 + цена у верхней BB (±1%) → шорт к средней BB
  BTC медвежий → MR_ЛОНГИ заблокированы (WR 36% без фильтра)
  Объём < 3x, стоп 0.2-0.4%
  RR 1:2

VOLATILE → пауза
```

**ML фильтр:** Random Forest, AUC 0.608, порог 0.40
Каждый сигнал проходит ML перед добавлением в pending.

**Параметры:**
```python
timeframes       = ["5m"]
channel_bars     = 15       # свечей для канала
bo_vol_mult      = 1.5      # объём на пробое
min_breakout_pct = 0.001    # минимальный пробой 0.1%
rsi_oversold     = 35
rsi_overbought   = 65
min_stop_pct     = 0.006    # стоп <0.6% — комиссия съедает >33% риска
max_stop_pct     = 0.03     # стоп >3% — слишком широкий для 5м
min_rr_mr        = 1.5      # минимальный RR для MR сигналов
bad_hours        = [14, 21, 22]
exchange         = "bitget"
```

**Статистика:**
```
Всего (старая стратегия): 604 сд  WR=23.5%
Новая стратегия (с 01.04): 20 сд  WR=50%
  MR_ШОРТ: WR=67%  PnL=+$4.35  ✅
  MR_ЛОНГ: WR=36%  (до фильтра BTC тренда)
  Channel BO: 0 сд (рынок пока не даёт пробоев)
```

### Бот #2 — Mean Reversion (Binance, 15m/1h)
**Режим:** SIDEWAYS

**Стратегия:** RSI + BB + ML фильтр, только ЛОНГИ

```
ШОРТЫ ОТКЛЮЧЕНЫ — математически убыточны:
  RR реальный 0.54 (WIN +$1.15 / LOSS -$2.12)
  Точка безубытка WR=65%, факт WR=42% → разрыв -23%
  107 сделок: SHORT PnL = -$32.35

ЛОНГИ работают:
  RR реальный 1.58 (WIN +$2.44 / LOSS -$1.54)
  Точка безубытка WR=39%, с ML фильтром WR=45%
```

**ML модель:** Random Forest, AUC 0.723 (только лонги)
OOS AUC 0.686, при пороге 0.40 WR=45% на тесте.

**Параметры:**
```python
timeframes     = ["15m", "1h"]
adx_max        = 25
rsi_oversold   = 30
rsi_overbought = 70   # не используется (шорты отключены)
min_rr         = 1.5
rr             = 2.0
```

**Статистика:** 107 сд, WR=36.4%, последние 20 сд WR=35%

### Бот #3 — Funding Rate (Bitget фьючерсы, 1h)
**Режим:** любой (лучший в TREND_DOWN)

**Стратегия:** контрариан по Funding Rate

```
FR < -0.03% → все шортят → ЛОНГУЕМ
FR > +0.03% → все лонгуют → ШОРТИМ
Подтверждение: RSI + BB
Лимитный ордер ±0.3%, RR 1:3
```

**Статистика:** 35 сд, WR=34.3%, PnL=-$38

**Наблюдение:** бот берёт малоликвидные монеты с аномальным FR.
ML модель исправит это автоматически после 60+ сделок с текущим WR.

## ML система

Обе обученные модели и весь датасет **потеряны** вместе с журналами
сделок (см. «Состояние» ниже). Но переобучать их по старой схеме и
не стоило — в подготовке данных были две утечки будущего:

| Что | Как было | Последствие |
|-----|----------|-------------|
| `hour`, `is_london`, `day_of_week` | считались от времени **закрытия** сделки | признака не существует в момент входа; на бою подставлялось время открытия — обучение и применение расходились |
| `regime` | брался на момент закрытия | то же самое |
| `risk_pct` (главный признак Bot1) | для сделок без стопа выводился как `abs(pnl)/deposit*entry` | вычислялся из реализованного PnL, то есть из ответа |
| Порог отсечки | подбирался на предсказаниях модели, обученной на всех данных | завышенный WR «при пороге» |

Поэтому **заявленные AUC 0.608 и 0.723 недействительны** — это не
измеренное качество, а следствие утечек. Критерий выхода на реал
«ML AUC >= 0.70» пока просто не проверен.

Утечки в коде закрыты: время и режим берутся на момент входа, риск
не выдумывается (есть флаг `has_stop`), боты сохраняют в сделке
`opened/stop/take`. Новые модели имеет смысл обучать на сделках из
бэктеста — их тысячи, а не десятки.

### Переобучение
```bash
python Bot1_EMA/ml_train_ema.py
python Bot2_MeanRev/ml_train_meanrev.py
```

```
Критерии выхода на реал:
  ✓ WR >= 35% на 200+ сделках (Bot1/2)
    или WR >= 30% на 60+ сделках с ML (Bot3)
  ✓ ML AUC >= 0.70
  ✓ Стабильность 2+ недели без деградации
  ✓ Просадка <= 20% за 30 дней
```

| Дата | Событие |
|------|---------|
| **07 апр 2026** | Bot3 достигает 60 сделок → обучаем ML |
| **09 апр 2026** | Bot2 достигает 200 сделок → оцениваем готовность |
| **Апр–Май 2026** | Bot1 новая стратегия: наблюдаем 100+ сделок |

| **🟢 Май 2026** | **Bot3 → реальные деньги** (если WR 30%+ с ML) |
| **🟢 Июнь 2026** | **Bot1 → реальные деньги** (если новая стратегия WR 40%+) |
| Авг–Дек 2026 | Bot4 накапливает 150+ сд → ML → оценка |

> Боты идут на реал последовательно — сначала самые стабильные.
> Начинаем с минимального депозита $100-200 на каждый бот.

## Бэктест

Проверка стратегии на истории вместо ожидания месяцами. Стратегия
не переписана — `Backtest/run.py` импортирует настоящие
`add_indicators` и `find_signals` из самого бота, поэтому бэктест и
бот не могут разойтись.

```bash
# Прогон за 3 месяца по 25 инструментам
python Backtest/run.py --start 2026-06-01 --end 2026-09-01 --symbols 25

# Сравнить модели исполнения
python Backtest/run.py --compare-fills

# Перепроверить каждую сделку по сырым свечам
python Backtest/validate.py
```

Чем модель исполнения отличается от бумажной торговли:

| | Бумажный бот | Бэктест |
|---|---|---|
| Стоп/тейк | опрос цены раз в 10 мин | high/low каждой свечи |
| Лимитка | цена подошла на ±0.3% | цена дошла до уровня |
| Проскальзывание | нет | есть на стопах |
| Плечо | не проверялось | объём режется под депозит |
| Стоп и тейк в одной свече | — | засчитывается стоп |

Ключи: `--fill limit|touch|market`, `--leverage`, `--risk`,
`--deposit`, `--slippage`, `--symbols`.

Свечи кэшируются в `Backtest/cache/`, поэтому из сети качается
только первый прогон.

### Первый результат (июнь–август 2026, 19 пар, 990 сделок)

```
WR 29.6%   точка безубытка 34.7%   profit factor 0.79   итог -88.6%
```

Стратегия убыточна, но интересно **почему**:

| | на сделку |
|---|---|
| Валовый край | **+0.048R** |
| Комиссия | **−0.207R** |
| Итого | −0.158R |

Край есть — он положительный. Но комиссия больше него в 4.3 раза.
Средний стоп 1.21% от цены, комиссия туда-обратно 0.2% — то есть
17% дистанции стопа отдаётся бирже на каждой сделке. При 990
сделках за три месяца это $36.91 комиссий на депозит $50: **83%
всего убытка — комиссии**, до них результат почти в нуле (−$7.39).

Разрез по ветвям стратегии (валовый R на сделку):

| Сигнал | Сделок | WR | До комиссий | Чистое |
|--------|--------|----|-------------|--------|
| MR_ЛОНГ | 120 | 35.0% | **+0.152R** | −0.121R |
| MR_ШОРТ | 351 | 34.5% | **+0.122R** | −0.149R |
| BO_ЛОНГ | 272 | 27.6% | **+0.077R** | −0.070R |
| BO_ШОРТ | 247 | 22.3% | **−0.138R** | −0.286R |

Три ветви из четырёх зарабатывают до комиссий. `BO_ШОРТ` убыточен
и до них — его надо отключать, ровно как в своё время отключили
шорты Bot2 по той же причине.

Отсюда направление работы: не «искать сигналы получше», а снижать
трение — реже сделки, шире стопы, старший таймфрейм, мейкерские
заявки вместо тейкерских.

**Оговорки.** Список пар построен по сегодняшним объёмам
(survivorship bias). Три месяца — один рыночный режим. Депозит $50
при 990 сделках означает, что размер позиции всё время упирался в
лимит плеча (100% сделок урезаны), поэтому долларовые суммы искажены
и смотреть надо на R.

Модели исполнения `limit` и `touch` дали **идентичный** результат:
вход ставится по цене закрытия сигнальной свечи, поэтому лимитка
исполняется в 100% случаев и поблажка ±0.3% ничего не меняла. Для
этой стратегии она была безвредна — но проверить это стоило.

## Найденная стратегия

Перебор 522 конфигураций трёх семейств правил с разделением истории
на обучение и проверку. **Проверочный период в отборе не участвовал.**

```
Пробой канала Дончиана, 4 часа
  вход  — закрытие выше максимума (ниже минимума) 20 свечей
  фильтр — лонги только выше EMA200, шорты ниже
  стоп  — 2.5 ATR, в среднем 6.5% от цены
  тейк  — 3 дистанции стопа
  выход по времени — 200 свечей (33 дня)
```

| | Обучение<br>2023-06 … 2025-06 | Проверка<br>2025-06 … 2026-09 |
|---|---|---|
| Рынок | BTC **+291%** | BTC **−25%** |
| Сделок | 407 | 250 |
| WR | 36.6% | 33.2% |
| На сделку | **+0.299R** | **+0.192R** |
| Комиссия | 0.045R | 0.047R |

Почему работает там, где Bot1 не работал: стоп 6.5% вместо 1.2%,
поэтому комиссия падает с 0.207R до 0.047R — в четыре с лишним раза.
Край стратегии при этом даже меньше по абсолютной величине, чем
хотелось бы, но теперь он больше трения, а не меньше.

### Что эта конфигурация пережила

- **Смену режима рынка.** Обучение пришлось на рост, проверка на
  падение (упали 17 пар из 19). На проверке **шорты дали больше
  лонгов** (+0.248R против +0.128R) — значит это не замаскированная
  покупка растущего рынка.
- **Другую биржу.** На Binance, где из 31 пары совпадают с исходным
  набором лишь 7, та же конфигурация без подгонки: обучение
  +0.193R, проверка +0.152R.
- **Не единственную настройку.** Из 144 конфигураций Дончиана 89%
  прибыльны на проверке, медиана +0.096R. Край не зависит от
  точного выбора параметров — это главное отличие настоящего
  преимущества от подгонки. Для сравнения: у возврата к среднему
  на проверке прибыльны 1% настроек, медиана −0.197R.
- **Каждое полугодие по отдельности** — все шесть в плюсе
  (от +0.083R до +0.395R).
- **Комиссию вдвое выше реальной.** Ноль достигается только при
  0.4% за сторону.
- **Funding по худшему сценарию.** При 0.01% за 8 часов остаётся
  +0.213R; ломается только при 0.1% — а шорт при положительной
  ставке funding не платит, а получает.

На счёте $500 при риске 1% на сделку проверочный период дал бы
+75% при максимальной просадке 19%; при риске 2% — +165% и
просадка 35%.

### Чего проверка НЕ снимает

- **Выживший отбор.** Список пар строится по сегодняшним оборотам,
  монеты, ушедшие в ноль, в выборку не попали. Это завышает
  результат на неизвестную величину.
- **250 сделок на проверке** при t-статистике 1.3–1.8. Это
  обнадёживает, но не доказывает: такое бывает и случайно.
- **Нужны перпетуальные фьючерсы** — шорты на споте невозможны.
  Funding оценён, но не смоделирован посделочно.
- **Это классический Дончиан**, стратегия «черепах» 1983 года. Что
  она не выдумана подгонкой — хорошо; что о ней знают все — повод
  не ждать многого.

### Проверка на фьючерсном наборе

Отбор шёл по спотовым парам, а бот торгует перпетуалами — наборы
разные, поэтому край подтверждён отдельно на том самом списке,
который бот и возьмёт (34 пары, белый список по споту Binance):

| Период | Сделок | WR | На сделку | Комиссия | t |
|---|---|---|---|---|---|
| Обучение | 340 | 38.5% | +0.359R | 0.019R | 3.67 |
| **Проверка** | 211 | 35.5% | +0.247R | 0.021R | 2.01 |
| Последний год | 159 | 37.1% | +0.301R | 0.022R | 2.10 |

На фьючерсах результат лучше спотового: комиссия 0.06% против 0.1%,
и трение падает до 0.02R.

**Но эти числа получены на одном наборе монет.** Устойчивость к
выбору инструментов проверена отдельно ниже, и честная оценка края
оказалась ниже — около +0.14R.

### Что проверено и НЕ работает

| Идея | Результат на проверке |
|---|---|
| Всегда Дончиан | **+0.261R** |
| Переключение стратегии по режиму рынка | +0.055R |
| Дончиан только в трендовых режимах | +0.177R |
| ML-фильтр поверх Дончиана | AUC **0.527** — бесполезен |

Смена стратегии по режиму рынка **вредит**. Пробой канала сам по
себе есть детектор смены режима, измеренный по самой монете;
внешний детектор по BTC добавляет запаздывание и чужую информацию.

ML-фильтр на обучении выглядит чудом (+0.306R → +2.097R, AUC 0.811),
а на проверке даёт AUC 0.527 — подбрасывание монеты. 384 обучающие
сделки на 9 признаков это просто мало, и аккуратность тут не
спасает. Задним числом это объясняет и старые AUC 0.608 / 0.723.

### Устойчивость к выбору монет — главная оговорка

Первые прогоны дали на проверке +0.247R при t=2.01. Повторный запуск
той же конфигурации на том же периоде дал **+0.104R при t=0.90** —
разница только в том, что список строится по текущим оборотам, и
между запусками топ-40 сдвинулся.

Поэтому край измерен на 30 случайных наборах по 40 монет из пула 51:

| | Обучение | Проверка |
|---|---|---|
| Медиана | +0.206R | **+0.144R** |
| Разброс | 0.092 | 0.105 |
| Диапазон | −0.057 … +0.387 | −0.089 … +0.386 |
| Наборов в плюсе | 97% | **93%** |
| 5-й … 95-й перцентиль | +0.070 … +0.332 | **−0.008 … +0.332** |

Честная оценка края — **около +0.14R на сделку**, а не +0.25R.
Названные ранее +0.247R были удачной выборкой из верхней части
распределения. Край при этом настоящий: 93% случайных наборов
прибыльны на проверке. Но 5-й перцентиль лежит чуть ниже нуля —
то есть невезение с составом монет вполне может съесть его целиком.

### Гипотетический счёт $50, один год вне обучения

Посчитано на 20 случайных наборах по 40 монет, а не на одном:

| Риск | Медиана | Худший | Лучший | Медиана просадки | Доля лет в минусе |
|---|---|---|---|---|---|
| 5% | $57 (+14%) | **$2** | $225 | **−80%** | **40%** |
| 2% | $82 (+64%) | $34 | $114 | −41% | 10% |
| 1% | $61 (+22%) | $50 | $100 | −23% | 5% |

При риске 5% медиана всего +14%, хотя матожидание на сделку
положительное: просадки съедают сложный процент быстрее, чем он
набегает. Это классическая переставка — при 40% шансе закончить год
в минусе и худшем случае $2 от депозита. Максимальная серия убытков
подряд — 11.

Риск 2% даёт медиану +64% при просадке 41% и 10% шансе закончить год
в минусе. Это и стоит в боте по умолчанию.

Следующий честный шаг перед любыми деньгами — форвард-тест на
бумаге по этим правилам: они зафиксированы в
`Backtest/strategies.py` как `FOUND_DONCHIAN_4H`, а торгует по ним
Бот #5.

### Младшие таймфреймы

Тот же перебор трёх семейств на фьючерсной комиссии (0.06%), тот же
зафиксированный набор монет, отложенный период в отборе не участвовал:

| ТФ | Стратегия | Медиана на проверке | Плюсовых настроек | Комиссия |
|---|---|---|---|---|
| **4h** | Дончиан | **+0.14R** | **93%** | 0.02R |
| 1h | Дончиан | +0.048R | 62% | 0.042R |
| 1h | Возврат к среднему | −0.113R | 0% | 0.045R |
| 1h | Откат к скользящей | −0.081R | 4% | 0.043R |
| 15m | Дончиан | −0.115R | 0% | 0.089R |
| 15m | Возврат к среднему | −0.155R | 0% | 0.093R |
| 15m | Откат к скользящей | −0.148R | 0% | 0.090R |
| 5m | Bot1 (первый бэктест) | −0.158R | — | 0.207R |

Чем младше таймфрейм, тем хуже — монотонно, без исключений. Причин
две, и они складываются:

- **комиссия в R растёт обратно дистанции стопа.** Предсказано до
  прогона и подтвердилось: ~0.04R на 1h, ~0.08R на 15m;
- **валовый край тоже падает.** На 15m Дончиан убыточен уже до
  комиссии (−0.026R), на 1h +0.09R, на 4h около +0.16R. На младших
  таймфреймах в пробоях больше шума и меньше продолжения.

На 15m провальны все 72 настройки трёх стратегий, включая лучшие по
обучению, на 3 600 сделках — это не недобор статистики, это
отсутствие края. Часовой Дончиан формально в плюсе, но втрое слабее
четырёхчасового и прибылен лишь в 62% настроек; менять на него 4h
смысла нет.

Непроверенный рычаг — мейкерские заявки: комиссия Bitget на
фьючерсах 0.02% против 0.06% у тейкера. На 1h это подняло бы край
примерно до +0.08R. Но у пробоев лимитный вход систематически
пропускает лучшие сделки — те, что сразу уходят, — поэтому без
отдельной проверки на это рассчитывать нельзя.

Данные для 1h и 15m взяты с Binance Futures (страница 1500 свечей
против 200 у Bitget, иначе 15m качались бы часами). Сетка меньше,
чем для 4h (24 настройки на семейство против 144), а 15m проверялся
на более коротком периоде — сравнение не идеально симметричное, но
направление однозначное.

## Широкий поиск: 13 семейств стратегий

После Дончиана перебор расширен на стратегии с другой механикой.
4 часа, комиссия фьючерсов, 33 монеты, обучение 2023-06…2025-06,
проверка 2025-06…2026-09. Всего 428 настроек.

```bash
python Backtest/test_strategies.py   # до всего: не падает и не подглядывает
python Backtest/test_engine.py       # регрессии движка
python Backtest/research_all.py      # перебор всех семейств
```

| Группа | Семейства |
|---|---|
| Тренд | Дончиан, пересечение скользящих, TSMOM, Кельтнер, Supertrend, MACD, RSI-моментум, откат |
| Волатильность | сжатие Боллинджера, NR7 |
| Возврат к среднему | RSI+BB, z-score |
| Портфель | кросс-секционный моментум (лонг сильных / шорт слабых) |

### Что нашлось

**Возврат к среднему не работает.** RSI+BB прибылен в 0% настроек,
z-score — в 3%. Это самый устойчивый результат всего поиска.

**Следование за трендом работает как класс** — но только при
правильном выходе. Выход оказался важнее входа:

| Тип выхода | Медиана по семействам | Семейств в плюсе |
|---|---|---|
| **Тейк 3R, без трейлинга** | **+0.102R** | **10 из 12** |
| Без тейка, трейлинг 3 ATR | +0.063R | 8 из 8 |
| Тейк 3R + трейлинг | +0.023R | 8 из 10 |
| Без тейка и трейлинга | −0.027R | 4 из 8 |

Трейлинг-стоп на 3 ATR **вредит**: выбивает сделки раньше, чем они
доходят до 3R.

**Два лидера, и оба прошли все барьеры** — случайные наборы монет и
другую биржу (данные Binance):

| | Bitget, проверка | Binance, проверка | Весь период, R/сделку |
|---|---|---|---|
| Дончиан 20 / ATR 2.5 / EMA200 (Бот #5) | +0.098R, 87% наборов | +0.099R, 100% | **+0.195 / +0.223** |
| Supertrend 3.0 / ATR 2.5 / EMA200 | +0.280R, 100% | +0.257R, 100% | +0.109 / +0.105 |

Supertrend выглядит втрое сильнее на проверке, но на обучении слабее,
и за все три года **Дончиан вдвое лучше на сделку**. Supertrend просто
больше подошёл медвежий 2025–26.

Главное — они **дополняют друг друга**:

| Полугодие | BTC | Дончиан | Supertrend | Вместе |
|---|---|---|---|---|
| 2023 П2 | +39% | +42.3R | +3.3R | +45.5R |
| 2024 П1 | +48% | +14.3R | +8.7R | +23.1R |
| 2024 П2 | +48% | +24.4R | +12.4R | +36.8R |
| 2025 П1 | +14% | +7.1R | +0.6R | +7.6R |
| 2025 П2 | −18% | +13.7R | +12.8R | +26.5R |
| 2026 | −11% | +9.2R | +14.0R | +23.2R |

(Bitget; на Binance картина та же.) Дончиан силён на росте,
Supertrend — на падении. Корреляция полугодовых результатов −0.23 на
Bitget и +0.04 на Binance, корреляция сигналов 0.12. Ни одного
убыточного полугодия ни у одной, ни у суммы.

Оговорка к «ни одного убыточного полугодия»: при таком крае и числе
сделок ожидалось бы около одного на шесть. Это скорее удача выборки,
чем свойство, — рассчитывать на отсутствие убыточных полугодий нельзя.

**Кросс-секционный моментум — эффект настоящий, но не торгуемый.**
Лонг сильных / шорт слабых даёт +32.6% в год до издержек — на четыре
стандартных отклонения выше случайного выбора монет, а его разворот
даёт зеркальные −31.3%, то есть расчёт честный. Но оборот съедает
почти всё: +1.9% чистыми. Лонг-онли вариант — это просто ставка на
рост рынка: +86% в год на обучении и −46% на проверке.

### Два бага, найденные по дороге

**Проверка на подглядывание была бесполезной.** Первая версия
сравнивала сигналы на истории до свечи N и на удлинённой истории — и
пропустила все три нарочно жульнические стратегии. Для всех свечей,
кроме последней, «будущее» существует в обоих вариантах. Теперь
история обрезается сразу после каждой свечи с сигналом; тест ловит
заглядывание на свечу вперёд, центрированное окно и нормировку на
максимум всей истории.

**R трейлинговых сделок считался неверно.** В сделку записывался
финальный, подтянутый стоп, и R = PnL / |вход − стоп| давал у КАЖДОЙ
прибыльной трейлинговой сделки ровно +1R — стоп и есть цена выхода. А
при стопе, подтянутом вплотную к входу, R улетал до +7. До исправления
трейлинг выглядел впятеро лучше фиксированного тейка; на деле он хуже.
Теперь хранится `initial_stop`, есть регрессионный тест.

Оба бага давали **ложно хорошие** результаты. Это главная причина
проверять не только стратегии, но и сами проверки.

## Бот #5 — Дончиан (Bitget перпетуалы)

Единственный бот проекта, правила которого не придуманы, а найдены
перебором и проверены на данных, которых отбор не видел.

```bash
Bot5_Donchian\start_bot5.bat                      # торговля
python Bot5_Donchian/paper_trading_donchian.py status    # статистика
python Bot5_Donchian/paper_trading_donchian.py symbols   # набор инструментов
```

Сигналы берутся импортом из `Backtest/strategies.py` — тем же кодом,
что и в бэктесте. Разойтись они не могут: правка правил меняет обе
стороны сразу.

Три вещи, которых не было в прежних ботах:

- **Стоп задаётся явно в ATR**, а не выводится из границ канала.
  В этом вся разница: 6.5% против 1.2% дистанции — и комиссия
  падает с 0.207R до 0.02R.
- **Выход проверяется по high/low закрытых свечей**, а не опросом
  текущей цены раз в N минут. Совпадает с бэктестом свеча в свечу.
- **Последняя, ещё формирующаяся свеча отбрасывается.** Биржа
  отдаёт её последним элементом, и сигнал по ней — это пробой,
  которого к закрытию может не остаться.

**Список инструментов зафиксирован** — 35 перпетуалов, отобранных
16.09.2026 по двум объективным признакам: оборот от $5М в сутки и
не меньше 1800 четырёхчасовых свечей истории. Плюс базовый актив
обязан листиться спотом на Binance: Bitget листит на перпетуалах
акции (SAMSUNG, LGELECTRONICS, SKHYNIX), плечевые ETF (KORU, SOXL)
и драгметаллы (XAU, XAG), а по обороту они пролезают в топ. Чёрный
список тут проигрывает — их сотни и появляются новые.

Результатов бэктеста в отборе нет намеренно: выбирать монеты по
тому, как они отработали на истории, значит подгонять состав под
ответ. Фиксация нужна потому, что край сильно зависит от состава
(см. выше разброс по наборам) — с плавающим списком форвард-тест
мерил бы удачу состава пополам со стратегией.

```bash
python Bot5_Donchian/paper_trading_donchian.py refresh-symbols
```
покажет, как список разошёлся с текущими оборотами, но сам ничего
не поменяет. Каждое обновление обнуляет чистоту накопленной
форвард-статистики.
